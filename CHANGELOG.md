# Changelog

## 0.9.2
- Extensions load from %APPDATA%\Ralenti\extensions and survive app updates

## 0.9.1
- Extensions can provide their own update instructions

## 0.9.0 · first public release
- Interpolate: smooth slow motion and higher frame rates with RIFE (free, open source, any Vulkan GPU)
- Preview takes with before/after and take-vs-take comparison in the player, switchable audio, looping
- Exact frame rates, natural-pitch or pitch-kept slow-motion audio, processing resolution
- Crop with black-bar detection, trim, presets with a default preset
- Encode to a VMAF target or constant quality; lossless Trim and Merge
- Resumable step-based queue with ETA, taskbar progress, sleep or shut down when done
- Downloads page: one-click install and updates for FFmpeg and RIFE
- Disk-space prediction, GPU/CPU/RAM meters, collapsible sidebar, accent colors
- Windows installer (per user, no admin) and portable zip
